Аутентификация
Ключ и пароль используются один раз для этой установки и не сохраняются. Дальше сервер управляет агентом через отдельного пользователя tgproxy-deploy с ограниченным sudo.
Выполните на хосте агента (токен действует 1 час, один раз) 
curl -fsSLO https://github.com/vasyakrg/tgproxy-server/releases/download/v1.4.1/tgproxy_1.4.1_amd64.deb
sudo dpkg -i tgproxy_1.4.1_amd64.deb
sudo tgproxy agent enroll \
  --server https://tgproxy.corp.example:8444 \
  --token enr_Q8vT2mXk9pLz4RwN7cYd1hGs \
  --ca-fingerprint SHA256:Xk2c9P0u…9Lw

Что сделает установщик

  1. Закрепит ключ хоста после подтверждения
  2. Зальёт deb той же версии, что у сервера
  3. Создаст пользователей tgproxy-agent и tgproxy-deploy
  4. Выпустит сертификат: ключ создаётся на агенте
  5. Запустит службу и проверит связь до api.telegram.org
  6. Добавит агента в балансировку с выбранным весом
Требования: Debian 11+ / Ubuntu 22.04+, x86_64, открытый TCP-порт агента для IP сервера.
